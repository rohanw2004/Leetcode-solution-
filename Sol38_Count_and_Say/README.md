LeetCode 38 - Count and Say

This problem is about reading the previous string and describing it.

For example:

"1 → 11 → 21 → 1211 → 111221"

I used a simple loop to build each term by counting consecutive same digits.

Languages

- Python
- Java

Example

Input: n = 4
Output: 1211

What I learned

The main thing here is understanding how to count consecutive characters and build the next string.
