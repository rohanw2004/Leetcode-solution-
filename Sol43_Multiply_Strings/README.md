# 43. Multiply Strings

Multiply two numbers given as strings without converting them into integers.

### Approach
I used the normal multiplication idea. Each digit is multiplied and the result is stored in an array, then converted back into a string.

### Example

Input:
num1 = "123", num2 = "456"

Output:
"56088"

### Complexity
Time: O(m × n)
Space: O(m + n)
