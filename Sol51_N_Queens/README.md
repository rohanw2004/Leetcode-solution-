LeetCode 51 - N-Queens
Solved LeetCode 51 using Python and Java.
Approach
I used backtracking to place queens on the chessboard. I checked rows, columns and diagonals to make sure no two queens attack each other.
Example
Input: "n = 4"
Output: "2 valid solutions"
Languages
- Python 3
- Java
Time Complexity
Approximately O(n! × n)
This problem helped me understand backtracking better.
