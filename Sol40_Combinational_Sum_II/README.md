LeetCode 40 - Combination Sum II

This solution finds all unique combinations of numbers that add up to the given target.

Approach

- Sort the array first.
- Use recursion to try different combinations.
- Skip duplicate numbers at the same level.
- Each number can be used only once.
- Add the combination when the target becomes "0".

Languages

- Python
- Java
