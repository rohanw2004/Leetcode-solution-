LeetCode 35 - Search Insert Position

This problem is about finding the position of a target in a sorted array.

I used Binary Search to solve it. If the target is found, I return its index. If it is not found, I return the position where it should be inserted.

Example

Input: nums = [1,3,5,6], target = 5
Output: 2

Input: nums = [1,3,5,6], target = 2
Output: 1

Complexity

- Time: O(log n)
- Space: O(1)

Solved in Python and Java.
