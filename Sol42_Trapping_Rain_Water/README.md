LeetCode 42 - Trapping Rain Water

Problem

Given an array of heights, find how much rainwater can be trapped between the bars.

Approach

I used the two pointer approach with "leftMax" and "rightMax" to keep track of the highest walls from both sides.

Example

"[0,1,0,2,1,0,1,3,2,1,2,1]"

Output: "6"

Complexity

- Time: O(n)
- Space: O(1)
